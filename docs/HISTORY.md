# 復原與歷史

已選標籤的每一次變更都會記錄，誤觸「清空」或重抽時可以救回。

## 操作

- **按鈕**：「目前選中標籤」標題右側的 ↩（復原）與 ↪（重做）。按鈕提示會顯示將復原或重做的動作，例如「復原：重抽「動作姿勢」」。
- **快捷鍵**：`Ctrl+Z`（Mac 為 `⌘Z`）復原；`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。焦點在文字欄位（如提示詞文字框）時保留瀏覽器原生的文字復原，不會攔截；勾選框、按鈕與下拉選單不影響快捷鍵。
- **歷史清單**：「🕘 歷史」可展開，由新到舊列出每個動作，最下面是「最初狀態」。點任一列即可跳到「該動作完成之後」的狀態；「目前」標示現在的位置，被復原的動作會變暗。

## 會被記錄的動作

| 動作 | 歷史中的名稱 |
| --- | --- |
| 點選加入標籤（含互斥取代） | 加入「X」 |
| 取消選取或按「❌ 剔除」 | 剔除「X」 |
| ➕／➖ 調整權重 | 調整「X」權重（連按會合併成一步） |
| 📌 釘選／取消釘選 | 釘選「X」／取消釘選「X」 |
| 隨機抽卡（全部或分類 🎲） | 重抽 N 個分類／重抽「分類」 |
| ❌ 清空重選 | 清空重選 |
| 匯入 JSON、貼上分享連結或代碼 | 載入工作階段 |

## 不會被記錄的動作

- 第一次載入時的隨機抽卡，以及啟動時自動還原上次的工作階段（這些不是你的操作）。
- 分類鎖定與鎖定快捷操作、「同類只抽一個」與「同群組只留一個」選項、平台與 2D／3D、尺寸、引擎、範本等**設定**：歷史只涵蓋「已選標籤、權重、釘選」。載入工作階段時，被復原的只有標籤；其他設定不會被復原。
- 前後沒有差異的動作（例如全部分類都已鎖定時的重抽）。

## 細節

- 最多保留 **50 步**，超過時丟棄最舊的。
- 復原後做了新動作，原本可重做的步驟會被丟棄（標準的線性歷史）。
- 歷史**只存在於記憶體**，重新整理頁面後會清空（工作階段的自動儲存仍會還原當下的標籤）。復原與重做後的結果會照常自動儲存。
- 歷史只儲存提示詞（英文原文）、權重與釘選，標籤名稱在顯示時依目前語言查詢，所以切換語言後歷史清單會以新語言重新顯示。

## 維護者

- 純邏輯在 `assets/js/history.js`（線性時間軸：每個項目保存前後快照，游標指向目前位置；`commit`、`undo`、`redo`、`jumpTo`、合併規則），有單元測試。
- 畫面端在 `app.js`：**任何會改變 `activeSelections` 的新動作，都要包在 `recordedChange(label, fn, options)` 裡**，否則不會進入歷史。`label` 是 `{ key, prompt?, sheetId?, count? }`，`key` 對應 `history.*` 語系鍵；要合併連續操作時傳入 `{ key: '合併用的鍵' }`。
- 還原狀態一律走 `restoreSelections`（會暫停記錄，避免重複）。
