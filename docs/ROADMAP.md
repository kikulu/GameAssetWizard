# Roadmap

以下排序以產品價值與實作風險為準，實際日期可依使用者回饋調整。優先度：**高**＝直接影響日常使用或專案可維護性；**中**＝明顯加分；**低**＝長期方向。

## 已完成

### v1.0 — 基礎整理

- [x] HTML、CSS、JavaScript 分離
- [x] 提供 Node.js 本機靜態服務與 Draw Things CORS 代理
- [x] 建立 GitHub 基礎檔案與開發文件
- [x] 保留 JSON 詞庫驅動的既有功能

### v1.1 — 本機產圖

- [x] 支援 Draw Things、SD WebUI／Forge 與 ComfyUI 本機產圖
- [x] 加入 sampler、scheduler、denoise、checkpoint、VAE、LoRA 與 ControlNet 參數
- [x] 支援提交 ComfyUI API workflow JSON

### v1.2 — 桌面版

- [x] Electron 桌面版與跨平台打包
- [x] 網頁／桌面共用的 `apiFetch()` 抽象層，桌面版免 CORS 代理

### v1.3 — 風格一致化

- [x] 將產圖參數保存為可重複使用的風格預設（風格鎖定）
- [x] 批次產圖與設定紀錄匯出
- [x] 風格鎖定單元測試（`npm test`）

### v1.4 — 多語系

- [x] 介面、產圖工作台與風格鎖定全面多語系（繁中、英、日、韓）
- [x] 標籤庫拆成語言中立結構與各語系檔案
- [x] 翻譯對照表（CSV／Markdown）與匯入、檢查、新增語言工具

### v1.5 — 抽卡與範本體驗

- [x] 隨機抽卡以群組為單位，同類只抽一個、重抽避開上次結果、分類單獨重抽
- [x] 創作範本面板重新設計（可收合、點選即套用）
- [x] 詞庫與設定檔結構驗證（`npm run validate`）

### v1.6 — 組合與輸出

- [x] 釘選標籤：重抽時保留喜歡的標籤，其所在群組不再另外抽
- [x] 依繪圖引擎輸出提示詞格式（Stable Diffusion、Midjourney 預設／v7／v6.1、Leonardo、Ideogram、DALL·E 3）
- [x] 工作階段自動儲存與還原、分享連結（桌面版為分享代碼）、JSON 匯出／匯入
- [x] 提示詞格式、工作階段與釘選的單元測試

### v1.7 — 鎖定與互斥

- [x] 鎖定整個分類：重抽時保持不變，清空時保留
- [x] 手動選取的「同群組只留一個」（群組＋單選子分類，釘選優先）
- [x] 資料欄位 `single` 與驗證

## 規劃中

### 抽卡與組合（建議下一版：v1.8）

- [ ] **互斥衝突的視覺提示**（中）：開啟互斥模式時，標籤上直接標示「會取代 X」，並讓互斥關係在詞庫中可見（目前只在點選後才發生替換）。
- [ ] **互斥規則的資料化擴充**（中）：目前只有 `group` 與 `single`；可加入「A 與 B 互相衝突」的明確配對（例如特定服裝與特定武器），並在 `npm run validate` 檢查。
- [ ] 分類鎖定的快捷操作（中）：全部鎖定／全部解除、鎖定目前已選內容所在的分類。
- [ ] **抽卡歷史與復原**（中）：保留最近 N 次結果，支援上一步／下一步與收藏。
- [ ] **可重現的抽卡**（中）：以種子抽卡，並可把「種子＋設定」放進分享連結，團隊能重現同一組提示詞。
- [ ] **加權抽卡**（中）：常用標籤提高機率、停用標籤排除；依模式或範本調整預設抽卡策略（例如 Steam 模式不抽 App 圖示群組）。
- [ ] **範本升級為「配方」**（中）：一個配方＝提示詞＋尺寸預設＋風格預設＋預設抽卡分類；支援把目前的選取另存為自訂範本，並匯出／匯入 JSON。
- [ ] 範本預覽縮圖與標籤搜尋、篩選、收藏（中）。
- [ ] 以參考圖鎖定畫風（IP-Adapter／img2img）（中）。

### 提示詞輸出與工作階段

- [ ] **Midjourney 進階參數與版本清單可設定化**（高）：版本迭代很快（目前預設為 V8.2）。把 `ENGINES` 抽成可編輯的 JSON，並提供 `--stylize`、`--chaos`、`--style raw`、`--seed`、`--weird` 等選填欄位；對 `--v` 與參數支援狀態做版本表，避免硬寫在程式。
- [ ] **使用者自訂引擎格式**（低）：以樣板字串定義前綴、權重語法、反向詞位置與參數，不必修改程式。
- [ ] 提示詞長度與 token 估算，過長時提示（中）。
- [ ] **多組具名工作階段**（中）：目前只有一個自動儲存槽；支援命名存檔、列表與切換，並可選擇性同步到使用者提供的檔案位置。
- [ ] 分享連結以 CompressionStream 壓縮並保留相容的舊格式；長連結改以檔案分享（低）。
- [ ] 標籤輸出順序規則（主體→服裝→動作→場景→鏡頭→風格），讓結果更穩定（中）。
- [ ] 負向提示詞預設集（人物、場景、UI 各一組）（低）。

### 產圖工作台

- [ ] 產圖佇列、取消與進度顯示（ComfyUI 可改用 WebSocket 取得進度）（中）。
- [ ] 圖片歷史紀錄（IndexedDB，僅本機）、並排比較，下載時把提示詞與種子寫入 PNG metadata（中）。
- [ ] 多組提示詞配方與版本比較（低）。

### 品質與維護

- [ ] **CI**（高）：GitHub Actions 在 Node 18／20／22 執行 `npm run check` 與 `npm test`。
- [ ] **端對端測試納入專案**（高）：把目前手動執行的瀏覽器流程（語言切換、範本、抽卡、風格鎖定與批次）整理為 Playwright 測試。
- [ ] 將 inline HTML event handler 改為集中式事件綁定，並加入 CSP（網頁與 Electron 皆適用）（中）。
- [ ] **無障礙**（中）：手風琴與標籤改用 `button`＋`aria-expanded`／`aria-pressed`、完整鍵盤操作、清楚的 focus 樣式、`prefers-reduced-motion`。
- [ ] **行動版與主題**（中）：窄螢幕改為底部抽屜式主控面板；提供淺色主題並跟隨系統設定。
- [ ] 全域錯誤提示（toast）與載入失敗重試（中）。
- [ ] 前端改為 ES modules（無需 TypeScript 也能先降低全域變數耦合）（中）。
- [ ] 詞庫量大時的搜尋與虛擬捲動（低）。
- [ ] PWA／離線模式（網頁版 service worker）（低）。

### 桌面版發佈

- [ ] 應用程式圖示、程式碼簽章（Windows／macOS 公證）與自動更新（高，對外發佈前）。
- [ ] 在 Windows、macOS、Linux 實機驗證打包結果（高）。

### 多語系與內容

- [ ] 日文、韓文標籤的母語校對，並在語系檔記錄「已校對」狀態（高）。
- [ ] 更多語言：簡體中文、西班牙文、法文、德文、葡萄牙文等（中）。
- [ ] 翻譯記憶匯出（XLIFF／PO），方便接入翻譯平台（低）。
- [ ] 詞庫品質檢查：語意重複、標籤長度、風格一致性提示（中）。
- [ ] 擴充標籤庫：載具、生物／怪物、材質、光影、色彩配置、構圖範例（中）。
