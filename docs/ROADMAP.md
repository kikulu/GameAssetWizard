# Roadmap

以下排序以產品價值與實作風險為準，實際日期可依使用者回饋調整。優先度：**高**＝直接影響日常使用或專案可維護性；**中**＝明顯加分；**低**＝長期方向。

## 已完成

- [x] HTML、CSS、JavaScript 分離
- [x] 提供 Node.js 本機靜態服務與 Draw Things CORS 代理
- [x] 建立 GitHub 基礎檔案與開發文件
- [x] 保留 JSON 詞庫驅動的既有功能

## 規劃中

### 抽卡與組合（建議下一版：v1.6）

- [ ] **釘選標籤**（高）：標籤可 📌 釘選，重抽時保留，只重抽其餘部分；解決「喜歡這個姿勢，想換服裝」的情境。
- [ ] **手動選取的同組互斥選項**（高）：在同一群組點選第二個標籤時，可選擇「取代」而非疊加（預設關閉，與抽卡的群組規則一致）。
- [ ] **抽卡歷史與復原**（中）：保留最近 N 次結果，支援上一步／下一步與收藏。
- [ ] **可重現的抽卡**（中）：以種子抽卡，並可把「種子＋設定」放進分享連結，團隊能重現同一組提示詞。
- [ ] **加權抽卡**（中）：常用標籤提高機率、停用標籤排除；依模式或範本調整預設抽卡策略（例如 Steam 模式不抽 App 圖示群組）。
- [ ] **範本升級為「配方」**（中）：一個配方＝提示詞＋尺寸預設＋風格預設＋預設抽卡分類；支援把目前的選取另存為自訂範本，並匯出／匯入 JSON。
- [ ] 範本預覽縮圖與標籤搜尋、篩選、收藏（中）。
- [ ] 以參考圖鎖定畫風（IP-Adapter／img2img）（中）。

### 提示詞輸出

- [ ] **依繪圖引擎輸出格式**（高）：目前所有引擎共用 `(tag:1.2)` 權重語法。Midjourney 應輸出自然語句與 `--ar`、`--v` 等參數、DALL·E 偏好完整句子，Stable Diffusion／ComfyUI 維持括號權重。
- [ ] 提示詞長度與 token 估算，過長時提示（中）。
- [ ] 標籤輸出順序規則（主體→服裝→動作→場景→鏡頭→風格），讓結果更穩定（中）。
- [ ] 負向提示詞預設集（人物、場景、UI 各一組）（低）。
- [ ] 自動儲存工作階段（選取、權重、設定），並可匯出／匯入 session JSON 或產生分享連結（高）。

### 產圖工作台

- [ ] 產圖佇列、取消與進度顯示（ComfyUI 可改用 WebSocket 取得進度）（中）。
- [ ] 圖片歷史紀錄（IndexedDB，僅本機）、並排比較，下載時把提示詞與種子寫入 PNG metadata（中）。
- [ ] 多組提示詞配方與版本比較（低）。

### 品質與維護

- [ ] **CI**（高）：GitHub Actions 在 Node 18／20／22 執行 `npm run check` 與 `npm test`。
- [ ] **端對端測試納入專案**（高）：把目前手動執行的瀏覽器流程（語言切換、範本、抽卡、風格鎖定與批次）整理為 Playwright 測試。
- [ ] 將 inline HTML event handler 改為集中式事件綁定，並加入 CSP（網頁與 Electron 皆適用）（中）。
- [ ] **無障礙**（中）：手風琴與標籤改用 `button`＋`aria-expanded`／`aria-pressed`、完整鍵盤操作、清楚的 focus 樣式、`prefers-reduced-motion`。
- [ ] **行動版與主題**（中）：窄螢幕改為底部抽屜式主控面板；提供淺色主題並跟隨系統設定。
- [ ] 全域錯誤提示（toast）與載入失敗重試（中）。
- [ ] 前端改為 ES modules（無需 TypeScript 也能先降低全域變數耦合）（中）。
- [ ] 詞庫量大時的搜尋與虛擬捲動（低）。
- [ ] PWA／離線模式（網頁版 service worker）（低）。

### 桌面版發佈

- [ ] 應用程式圖示、程式碼簽章（Windows／macOS 公證）與自動更新（高，對外發佈前）。
- [ ] 在 Windows、macOS、Linux 實機驗證打包結果（高）。

### 多語系與內容

- [ ] 日文、韓文標籤的母語校對，並在語系檔記錄「已校對」狀態（高）。
- [ ] 更多語言：簡體中文、西班牙文、法文、德文、葡萄牙文等（中）。
- [ ] 翻譯記憶匯出（XLIFF／PO），方便接入翻譯平台（低）。
- [ ] 詞庫品質檢查：語意重複、標籤長度、風格一致性提示（中）。
- [ ] 擴充標籤庫：載具、生物／怪物、材質、光影、色彩配置、構圖範例（中）。
