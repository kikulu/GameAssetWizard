# 介面語言

頁面右上方可切換 **繁體中文、English、日本語、한국어**。選擇會儲存在瀏覽器 `localStorage`，下次開啟時自動套用；首次開啟時依瀏覽器語言決定（中文 → 繁體中文，日、韓對應各自語言，其餘為英文）。

所有介面文字、標籤庫、模式與尺寸預設、創作範本與產圖工作台（含風格鎖定與批次產圖）皆已多語系化。提示詞本身維持英文，只翻譯顯示文字。

- 語系檔結構、翻譯流程（含試算表對照表）與新增語言：見 [多語系與翻譯指南](I18N.md)。
- 對照表：[`docs/i18n/translation-table.md`](i18n/translation-table.md)（CSV 版為 `translation-table.csv`）。
- 各語言說明文件：`README.md`（繁體中文）、`README.en.md`、`README.ja.md`、`README.ko.md`。新增語言時請一併建立 `README.<code>.md`。

日文與韓文的標籤由機器輔助起稿，歡迎母語使用者校對並提交 PR。
