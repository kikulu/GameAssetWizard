# 風格一致化產圖流程

讓同一系列的素材（角色、道具、圖示、商店圖…）維持相同畫風。位於「本機產圖工作台」最上方的 **🎨 風格鎖定** 區塊。

## 建議流程

1. 在下方產圖參數區調好 Steps、CFG、Sampler、Checkpoint、LoRA 等。
2. 在風格區填入 **風格名稱**、**風格前綴提示詞**（例如 `flat vector, thick outline, pastel palette`）與 **風格反向詞**。
3. 選擇種子模式：**固定種子**（較一致）或每張隨機；按 🎲 可重新抽一個種子。
4. 按 **📌 擷取目前參數**，再按 **💾 儲存**。
5. 勾選 **啟用風格鎖定**。參數欄位會被鎖住，之後的每次產圖都會自動：
   - 把風格前綴放在提示詞最前面；
   - 把風格反向詞併入反向提示詞（自動去除重複項目）；
   - 使用鎖定的參數與種子。
6. 在 **批次素材清單** 每行輸入一個素材，按 **🚀 批次產圖**。完成後可 **全部下載**，或 **匯出設定紀錄**（manifest JSON，內含每張圖實際使用的提示詞、種子與參數）。

## 風格分享

- **📤 匯出** 會產生 `style_<名稱>.json`，可交給同事或放進 Git；**📥 匯入** 會驗證格式後載入（同名時會詢問是否覆蓋）。
- 風格預設存在瀏覽器／Electron 的 `localStorage`，清除網站資料即會消失，重要風格請先匯出備份。

## 限制

- 固定種子能穩定構圖與色調，但提示詞不同時畫面仍會變化；要更強的一致性請固定 Checkpoint 與 LoRA。
- 批次最多 50 項；連續失敗 3 次會自動中止。
- ComfyUI 搭配自訂 workflow 時，提示詞與種子取決於你貼入的 workflow 內容。
- 目前介面文字為繁體中文（與產圖工作台一致），尚未納入 i18n 翻譯表。
