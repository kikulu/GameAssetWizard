# 工作階段：自動儲存與分享

主控面板最上方的「💾 工作階段」讓你不會因為重新整理而丟掉組合，也能把組合交給別人。

## 內容

| 會儲存 | 不會儲存 |
| --- | --- |
| 已選標籤、權重與釘選狀態 | API 位址（Draw Things／SD WebUI／ComfyUI） |
| 平台與 2D／3D、尺寸預設與寬高 | 產圖參數（Steps、CFG、Sampler、Checkpoint、LoRA、種子…） |
| 繪圖引擎、背景、品質 | 風格預設（請使用風格鎖定的匯出／匯入） |
| 目前套用的範本 | 介面語言（獨立儲存在瀏覽器） |
| 隨機抽卡的分類勾選、「同類只抽一個」、鎖定的分類，以及「同群組只留一個」選項 | 產圖結果與圖片 |

提示詞以**英文原文**為鍵，所以分享給使用不同介面語言的人也能正確還原。

## 自動儲存

每次變更後約 0.5 秒自動寫入瀏覽器的 `localStorage`（鍵 `session-v1`），下次開啟時自動還原並顯示「已還原上次的工作階段」。清除網站資料會一併清除。

## 分享連結

- **網頁版**：「🔗 複製分享連結」會複製 `…/index.html#s=<代碼>`。對方開啟後會載入你的組合，網址隨即清空，不會覆蓋他之後的變更。**分享連結優先於對方自己的自動儲存內容。**
- **桌面版**：桌面版沒有公開網址，按鈕改為「複製分享代碼」。對方把代碼貼到「貼上分享連結或代碼」欄位後按「套用」（網頁版也能貼代碼或完整連結）。
- 連結超過約 3000 字元時會提示改用匯出 JSON（部分聊天工具會截斷長連結）。

## 匯出與匯入

- 「📤 匯出 JSON」下載 `game-asset-session_日期.json`，格式為 `{ "format": "game-asset-session/1", "exportedAt": …, "state": { … } }`。
- 「📥 匯入 JSON」讀取同格式檔案。也接受只含 `state` 內容的物件。
- 「♻ 重設」清除自動儲存內容並重新整理頁面（會先確認）。

> 復原歷史（見[復原與歷史](HISTORY.md)）只存在記憶體，不會存入工作階段。

## 安全與相容性

載入任何工作階段（自動儲存、連結、代碼、檔案）都會經過 `Session.sanitize`（`assets/js/session.js`）：

- **只接受目前詞庫中存在的提示詞**，不存在的會略過並提示數量，所以無法透過連結把任意文字塞進提示詞。
- 引擎、平台、2D／3D、範本、背景與品質都必須是目前可用的選項，否則回到預設；權重限制在 0.2–2.0，寬高限制在 16–16384。
- 標籤最多 300 個、分享代碼最長 20000 字元。
- 詞庫改版後舊的工作階段仍可載入，只會略過已不存在的標籤。

## 維護者

- 純邏輯（驗證、編碼、檔案格式）在 `assets/js/session.js`，有單元測試；讀寫畫面狀態在 `assets/js/session-ui.js`。
- 新增要儲存的設定：在 `session-ui.js` 的 `capture()` 與 `apply()` 加入欄位，並在 `session.js` 的 `sanitize()` 驗證，補測試。
- `app.js` 在 `updateUIAndOutput()` 結尾呼叫 `scheduleSessionSave()`，載入設定完成後呼叫 `restoreSession()`；套用順序為「範本 → 模式 → 尺寸 → 引擎與規格 → 抽卡設定 → 標籤」，調整時請維持。
