# 隨機抽卡

「🎲 指定分類隨機抽卡」會在勾選的分類中各抽出一組標籤，並取代這些分類目前已選的標籤。

## 為什麼要分群組

舊版會「每個子分類抽一個」。姿勢分類有 4 個子分類，所以一次會抽到 4 個姿勢；服裝一次會同時出現奇幻、科幻、日常三件主服裝。現在改為以**群組**為單位：

- 結構檔中帶有相同 `group` 的子分類**互為替代**，整組只抽一個。
- 沒有 `group` 的子分類各自成一組（例如髮型與髮色、種族與職業，這些本來就該各有一個）。

| 分類 | 群組 | 一次抽到 |
| --- | --- | --- |
| 動作姿勢 | `pose`（4 個子分類） | 1 個姿勢 |
| 表情情緒 | `expression`（3 個） | 1 個表情 |
| 服裝造型 | `outfit`（3 個）＋配件 | 1 件主服裝＋1 個配件 |
| 場景環境 | `location`（3 個）＋背景素材 | 1 個場景＋1 個背景素材 |
| 道具裝備 | `weapon`（2 個）＋護甲＋消耗品 | 1 把武器＋1 件護甲＋1 個道具 |
| 特效 | `main-effect`（2 個）＋氛圍 | 1 個主特效＋1 個氛圍 |
| UI 元素 | `ui-element`（3 個） | 1 個 UI 元素 |
| 圖示徽章 | `icon`（3 個） | 1 個圖示 |
| 商店行銷 | `deliverable`（3 個） | 1 種素材 |
| 鏡頭構圖、髮型髮色、種族職業 | 無 | 各子分類 1 個 |

## 行為細節

- **先挑子分類，再挑標籤**：同一群組內先均勻挑一個子分類，再從中挑標籤，避免標籤數量多的子分類佔盡機會。
- **避免重複**：重抽時會盡量避開這些分類目前已選的標籤，連續抽卡不會抽到同一個結果；只有當所有候選都被避開時才允許重複。
- **只重抽單一分類**：每個分類標題右側的 🎲 只會重抽該分類，不影響其他分類，也不需要勾選。
- **舊行為**：取消勾選「🎯 同類只抽一個」會回到「每個子分類各抽一個」，選擇會記在瀏覽器中。
- 這個設定只影響隨機抽卡；手動點選標籤不受限制，仍可在同一群組選多個。

## 維護者：調整群組

編輯 `config_sheets/<sheetId>.json`，在子分類加入 `"group": "<kebab-case id>"`：

```json
{ "id": "combat-actions", "group": "pose", "tags": ["battle stance", "sword swing pose"] }
```

群組僅在同一個分類檔內有效。修改後執行 `npm run validate` 與 `npm test`。邏輯位於 `assets/js/randomizer.js`（純函式，有單元測試）。
